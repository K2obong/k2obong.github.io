# 조기행 디지털 명함 앱 (PWA)

폰 홈 화면에 아이콘으로 설치해서, 손님 앞에서 열어 보여주는 명함입니다.

- **명함 화면** — 상단 2/3에 이름·직함·연락처, 하단 1/3에 QR
- **상세 화면** — "상세 정보 보기 ▾"를 누르면 도메인 태그와 vCard 저장 버튼
- **오프라인 동작** — 한 번 열어두면 신호가 없어도 열립니다
- **화면 꺼짐 방지** — 명함 화면에서는 화면이 자동으로 꺼지지 않습니다(지원 기기)
- **전화번호 비노출** — 공개 웹이므로 전화번호는 화면과 소스에 평문으로 두지 않습니다. QR 안에는 들어 있고, "전화번호 보기"를 탭하면 화면에 나타납니다

---

## 폴더 내용물

```
card/
├── index.html                    앱 본체 (QR 그림이 안에 들어 있음)
├── manifest.json                 홈 화면 설치 설정
├── sw.js                         오프라인 지원
├── apple-touch-icon.png          아이폰 아이콘
├── android-chrome-192x192.png    안드로이드 아이콘
├── android-chrome-512x512.png    안드로이드 아이콘(고해상도)
└── favicon.ico                   브라우저 탭
```

파일 이름은 **하나도 바꾸지 마세요.** 정해진 이름을 찾아서 쓰기 때문입니다.

## 배포 (GitHub Pages)

### 1. 저장소 만들기

GitHub에서 새 저장소를 만듭니다. 이름은 반드시 **`k2obong.github.io`** — 본인 아이디와 정확히 같아야 개인 사이트로 인식됩니다. **Public**으로 만드세요.

### 2. 올리기

저장소 화면에서 `Add file` → `Upload files`로 **`card` 폴더를 통째로** 끌어다 놓습니다. 폴더 구조가 유지되어 `card/index.html` 형태가 되어야 합니다.

### 3. Pages 켜기

`Settings` → 왼쪽 `Pages` → Source를 `Deploy from a branch`, 브랜치는 `main` / 폴더는 `/ (root)` → Save.
1~2분 뒤 주소가 살아납니다:

```
https://k2obong.github.io/card/
```

### 4. 폰에 설치

1. 위 주소를 **카톡 나에게 보내기**로 폰에 전송합니다
2. **⚠️ 카톡 안에서 바로 열면 설치 메뉴가 없습니다.** 오른쪽 아래 메뉴에서 `Safari로 열기` / `다른 브라우저로 열기`를 고르거나, 주소를 복사해 브라우저 주소창에 직접 붙여넣으세요
3. **아이폰(Safari)** — 하단 공유 버튼 → `홈 화면에 추가`
   **안드로이드(Chrome)** — 우측 상단 점 3개 → `홈 화면에 추가` / `앱 설치`
4. 홈 화면에 **KH** 아이콘, 이름은 **명함**으로 생깁니다

### 5. 확인

- [ ] 아이콘을 눌러 **주소창 없이 전체화면**으로 열리는가
- [ ] 이름·연락처가 팔 뻗은 거리에서 읽히는가
- [ ] **다른 폰 카메라로 QR을 비춰** 연락처 저장 화면이 뜨는가
- [ ] 비행기 모드로 바꾼 뒤에도 앱이 열리는가 (오프라인 확인)

## 고칠 때

### 글자·색만 바꾸는 경우

`index.html`을 열어 고친 뒤, **`sw.js`의 `VERSION`을 올리고**(`card-v1` → `card-v2`) 저장소에 다시 올립니다.

> **버전을 안 올리면 폰에 남아 있던 옛 화면이 계속 보입니다.** 오프라인 지원의 대가이고, 이 한 줄로 해결됩니다.

### 전화번호를 다루는 방식

저장소가 Public이라 페이지 소스는 누구나 읽을 수 있습니다. 수집 봇이 번호를 긁어가지 못하도록 `PROFILE`의 `tel`을 인코딩해 두었습니다(`atob('...')`). 암호가 아니라 **자동 수집 차단용**이며, 사람이 소스를 뜯어보면 볼 수 있습니다.

- 화면에는 **"전화번호 보기"를 탭했을 때만** 표시됩니다
- **QR과 vCard 저장 버튼에는 그대로 들어 있습니다** — 손님이 QR을 찍으면 번호까지 저장됩니다
- 이메일도 같은 방식으로 감추고 싶으면 말씀해 주세요

### 연락처·직함을 바꾸는 경우

`index.html` 안 `PROFILE` 블록(스크립트 맨 위)을 고칩니다. 화면과 vCard 저장 버튼은 즉시 반영됩니다.

**단, QR 그림은 미리 그려 넣은 것이라 자동으로 바뀌지 않습니다.** QR도 다시 만들어야 하니 저에게 말씀해 주세요.

### 소속(회사·기관)을 넣는 경우

`index.html`의 `PROFILE` 아래쪽, `// 'ORG:' + esc('소속 기관명'),` 줄의 주석을 풀고 기관명을 넣으세요. 주소록에서 이름 아래에 표시됩니다.

## 남은 작업

- **소개 페이지** — `k2obong.github.io` 루트(`card` 폴더 바깥)에 `index.html`을 두면 그 주소가 소개 페이지가 됩니다. QR과 vCard의 URL이 이미 이 주소를 가리키고 있습니다.
- **공유 미리보기** — 배포 주소가 확정되면 `index.html` 상단의 `og:url` / `og:image` 두 줄 주석을 푸세요. 카톡으로 링크를 보낼 때 미리보기 카드가 뜹니다.
